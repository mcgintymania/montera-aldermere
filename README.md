# Montera: The Lanterns of Aldermere

A retro monster-catching adventure that runs in the browser. Catch Wildmon in glass Lanterns, earn the eight Badges from Aldermere's Halls, stop the Hollow Order, and take on the Gatekeepers of the Lantern League.

- **Play:** open `index.html`, or the GitHub Pages address for this repository.
- **Companion Guide:** `companion.html` has every Wildmon, move, item, place and Hall, a type chart, a team builder and a page that reads your saves.

## Install it as an app

Montera is a Progressive Web App. Once it is opened from the GitHub Pages address it works offline.

- **Android / Chrome / Edge:** pick *Install App* on the title screen, or *Install app* from the browser menu.
- **iPhone / iPad:** open it in Safari, tap *Share*, then *Add to Home Screen*.
- **Desktop Chrome / Edge:** use the install icon in the address bar.

Saves are kept on the device, in three slots. Use *Load / Manage Saves → Export file* on the title screen to back one up or move it to another device.

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | Arrow keys or WASD | D-pad |
| Confirm / talk | Z, E, Enter or Space | A |
| Back | X or Backspace | B |
| Run | Hold Shift (or B) | Hold B |
| Menu | Esc or M | Menu |
